Why NEXUS

Keep the conversation close to the code it is about.

One workspace for asking, editing, and trying things out.

Open a project and discuss its files with the model configured for your NEXUS server. The file explorer, editor, chat, and terminal work side by side, so you can investigate a problem without losing the thread.

Review proposed edits before applying them. Backups and undo help you recover from changes; running a program still happens when you choose to start it.

What you can do

Practical tools around the conversation.

Use the parts that fit your task. What is available depends on your account, server configuration, and installed tools.

01

Ask about a project

Discuss a workspace with relevant files in context. Attach text or code, drag files into chat, or use @ to find a file.

02

Edit with a review step

Inspect proposed changes before they are written. Backups, undo, and syntax feedback help you review the result.

03

Run code beside the editor

Build and run supported languages in the integrated terminal using toolchains installed on the NEXUS server.

04

Keep chats organized

Saved chats, editable titles, and brief cross-chat context help you pick up where you left off. Temporary chats stay separate.

05

Use a private scratchpad

Draft code in the account-specific notepad, run it in the terminal, or save a copy into the project.

06

Make visual work

When local ComfyUI tools are configured, Media Studio can create images and use a configured video workflow. Still-image clips use camera motion.

07

Browse alongside the work

Open links and project HTML in the embedded browser. Pages that block embedding can still open in your regular browser.

08

Pick a model setup

Use the provider configured for your server, including local Ollama, curated NEXUS Brain references, or the experimental CodeAI Personal Model.

Data and control

Know where your work goes.

NEXUS is self-hosted. Your chats and project files live on the server you use. Prompts and selected project context are sent to the model provider configured for that server.

01

Server storage

Chat history and project data are stored by your NEXUS server. Access from another device requires that server to be reachable.

02

Model provider

With local Ollama, inference runs through the Ollama server configured for NEXUS. Other providers may process prompts on their own service.

03

Your approval

Review proposed project edits before applying them. Chat-based training is a separate admin option and is off by default.

Good to know

Before you begin.

A few notes about using a self-hosted NEXUS website.

What is NEXUS?

A self-hosted software workspace that brings model-backed chat, project files, an editor, reviewed changes, and a terminal into one browser app.

Do I need to install anything?

You need access to a running NEXUS server and an account. The server operator installs and configures NEXUS; you use it in a browser.

Where are chats and project files stored?

They are stored on the NEXUS server you connect to. Prompts and selected file context are sent to the model provider configured for that server.

Which models can I use?

The server operator chooses available providers and models. Ollama can run locally; NEXUS Brain Lite is a small curated reference matcher, while the from-scratch CodeAI Personal Model is experimental.

Can NEXUS change my files or run code on its own?

Project edits require your review before they are applied, and Build & Run starts when you choose it. Programs run with the NEXUS server account permissions, so only run code you trust.

Can I generate pictures or videos?

Media Studio needs local ComfyUI setup. Images use an installed checkpoint; AI video needs a compatible local model and API-format workflow. Animating a still creates a camera-move clip, not new AI-generated frames.

Does NEXUS train on my chats?

No, not by default. An administrator can enable background learning in settings. Ask the server operator which options are enabled before sharing sensitive information.

Can I use it on another device?

Yes, if the device can reach the same NEXUS server and you sign in to the same account.

Contact

Contact your NEXUS operator.

Each server is managed independently. For account access, model availability, or help setting up this instance, contact the person who runs it.
